八年級上 · 第四章 4-1 因式分解解一元二次方程式

乘起來是 0，其中一個一定是 0

3-1、3-2 學會把式子拆成相乘：x²−x−6 → (x−3)(x＋2)。
這一節拿它來解方程式：(x−3)(x＋2)＝0，兩個括號相乘是 0，所以 x−3＝0 或 x＋2＝0，答案一眼就看出來。

先確認你知道這些

七上的一元一次方程式：2x−9＝−5x＋12

移項時，＋變−、−變＋、×變÷、÷變×（課本 p.151 Are You Ready?）：2x＋5x＝12＋9，7x＝21，x＝3。

這一節每一題的最後一步，都是解兩個像 2x−3＝0 這樣的一次方程式。

3-1 提公因式與乘法公式

AB＋AC＝A(B＋C)；a²−b²＝(a＋b)(a−b)；a²±2ab＋b²＝(a±b)²。

例 2、3、4、6 都要用到。忘了先回 3-1。

3-2 十字交乘法：x²−3x＋2＝(x−1)(x−2)

找兩個數，相乘是常數項、交叉相加是中間項：(−1)×(−2)＝2，(−1)＋(−2)＝−3。

例 5、7、8 都要用到。忘了先回 3-2。

1這一節在教什麼

四件事，先認熟

① 一元二次方程式（課本 p.152）
ax²＋bx＋c＝0　（a≠0）

三個條件：有等號、只有一種未知數（一元）、x 的最高次數是 2（二次）。
要先化簡再判斷：x²＋3x＝x²−13 兩邊的 x² 會消掉，剩 3x＋13＝0，是一次，不是一元二次。
x²＋x−3 沒有等號，只是一個多項式，也不是方程式。

② 解（根）（課本 p.153–154）
代進去，等號兩邊一樣 → 它是解

「解」和「根」是同一件事。判斷一個數是不是解：代進去算算看。
例：x＝−1 代入 x²−5x＝−2x＋4，左邊 1＋5＝6，右邊 2＋4＝6，一樣，所以 −1 是解（例 1）。
可是要「找」解，一個一個試太慢了，所以要學下面的方法。

③ A×B＝0，則 A＝0 或 B＝0（課本 p.155–160）
(x−3)(3x−2)＝0　→　x−3＝0 或 3x−2＝0

兩個數都不是 0，乘起來不可能是 0。所以乘積是 0，至少有一個是 0。
做法固定四步：移項讓一邊是 0 → 因式分解 → 每個因式等於 0 → 解兩個一次方程式。
分解用 3-1、3-2 的四招：提公因式（例 2、3）、先移項再提（例 4）、十字交乘（例 5）、乘法公式（例 6）。
⚠️ 只有乘積是 0 才能這樣拆。(x−4)(2x−7)＝1 不能拆成「x−4＝1 或 2x−7＝1」（p.162 動動腦）。

④ 重根（課本 p.161）
(3x＋2)²＝0　→　x＝−23（重根）

完全平方的方程式，兩個括號一模一樣，兩個解也一樣。這個解叫重根，寫成 x＝−⅔ 或 −⅔，或 x＝−⅔（重根）。

2為什麼要先因式分解

X-man 怎麼一下子就猜到小翊幾歲？

課本 p.152 的漫畫：X-man 要小翊把「今年的年齡」和「10 年前的年齡」相乘，小翊說是 39。X-man 馬上說：「我知道你的年齡了。」

設小翊 x 歲：x(x−10)＝39
展開、移項：x²−10x−39＝0
十字交乘：(x−13)(x＋3)＝0
所以 x＝13 或 x＝−3。年齡不會是負的，小翊 13 歲。驗算：13×3＝39 ✓

上面實驗一的第二個方程式就是這一題。用代入法要從 1 歲一路試到 13 歲；因式分解一次就找到。

代入法有多慢？

課本 p.154 舉了 2x²−87x−135＝0。它的解是 45 和 −1.5——誰會想到去試 45、更不會想到去試 −1.5？
用十字交乘分解成 (2x＋3)(x−45)＝0，兩個解馬上出來：x＝−32 或 x＝45。

📌 3-1 提過：英國數學家哈里奧特（Thomas Harriot）的代數書在 1631 年出版，書裡把方程式寫成幾個括號相乘等於 0。這一節做的就是這件事：先拆成相乘，再一個一個讓括號等於 0。

第 4 章後面會用到

    解題四步（課本 p.165）

    ① 移項，讓等號一邊是 0。
    ② 因式分解：先看公因式，再看乘法公式，最後十字交乘。
    ③ 每一個因式等於 0。
    ④ 解出兩個一次方程式，寫「x＝□ 或 x＝□」；兩個一樣就寫「（重根）」。

    三個最容易錯的地方（課本兩個動動腦、p.167 挑錯題）

    ① 兩邊同除含 x 的式子

    x(x＋3)＝2(x＋3) 兩邊同除 (x＋3) 得 x＝2，漏了 x＝−3。x＋3 可能是 0，不能除。要移項再提公因式：(x＋3)(x−2)＝0。

    ② 右邊不是 0 就拆

    (x−4)(2x−7)＝1 不能寫成 x−4＝1 或 2x−7＝1。兩個數相乘是 1 有無限多種（2 和 ½、−1 和 −1……）。只有乘積是 0 才能拆。

    ③ 十字交乘正負號放反

    小妍把 x²−2x−8 分解成 (x＋4)(x−2)，乘開中間是 ＋2x，不是 −2x。正確是 (x−4)(x＋2)。解完代回去驗算一次，就抓得到。
