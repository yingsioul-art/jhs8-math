先讓一邊是 0，再拆成相乘

這一頁每一題都照同一個順序想：等號一邊是 0 了嗎？另一邊拆得成相乘嗎？
每一行算式前面有一個小標籤：移項 讓一邊變 0；提公因式、十字交乘、平方差、完全平方 是 3-1、3-2 的分解方法；A×B＝0 把一個方程式拆成兩個一次方程式。
這一節大部分的錯，都是右邊還不是 0 就開始拆，或是兩邊同除含 x 的式子。

A×B＝0 的格子，排成一個十字

下面是一張乘法表：左邊是 A、上面是 B，格子裡是 A×B。點任何一格看看它是怎麼乘出來的。再按「只亮乘積是 0 的格子」。

乘法表 ── 哪些格子是 0
點一格看看。

📌 乘積是 0 的格子，全部在 A＝0 那一列或 B＝0 那一行，排成一個十字。十字外面一格 0 都沒有。
所以「A×B＝0」只有兩種可能：A＝0，或 B＝0（也可能兩個都是 0，就在十字正中間）。這就是課本 p.155 問題探索的結論。

解一元二次方程式的四步

第一步：移項（p.158、p.162）

把所有東西搬到等號左邊，右邊一定要是 0。右邊是 1、是 14 都不能往下做。

第二步：因式分解（p.156–160）

先看公因式，再看乘法公式，都不行就十字交乘。係數有分數或公因數，可以先同乘或同除。

第三步：每個因式等於 0（p.155）

一個方程式變成兩個一次方程式。

第四步：解一次方程式（七上）

兩個解一樣，就寫「x＝□（重根）」。

⚠️ 兩件不能做的事：
① 兩邊同除含 x 的式子，例如同除 (x−1)：x＝1 時是除以 0，會把一個解弄丟（p.158 動動腦）。
② 右邊不是 0 就拆： 不能寫成 x−4＝1 或 2x−7＝1（p.162 動動腦）。
