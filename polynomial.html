先確認你知道這些

「同類項」是什麼？（七年級學過）

x 的次方一樣的項，就是同類項。

5x2 和 −3x2 是同類項（都是 x²）；
2x 和 7x 是同類項（都是 x）；
但 5x2 和 2x 不是——次方不同，不能合併。

📌 合併的時候只加減係數，x 的部分不動：5x2 − 3x2 ＝ 2x2。

去括號要注意什麼？（七年級學過）

括號前面是加號：直接去掉，裡面不變。
3 ＋ (5 − 2) ＝ 3 ＋ 5 − 2

括號前面是減號：裡面每一項都要變號。
3 − (5 − 2) ＝ 3 − 5 ＋ 2

📌 這一節唯一的那道會考題，考的就是這件事。

1這一節在教什麼

四件事，一次看清楚

① 什麼叫「x 的多項式」
4　　2x　　x2 ＋ 3x ＋ 3

由數和文字符號 x，只用加法和乘法組出來的式子。
⚠️ 課本特別註明：當 x 出現在分母或絕對值裡面，就不是 x 的多項式（例如 2/x、|x|）。

② 項、係數、次數
a x2 ＋ b x ＋ c

用加號隔開的每一部分叫做「項」。
a 是 x² 項的係數、b 是 x 項的係數、c 是常數項。
係數不為 0 的最高次項，它的次數就是整個多項式的次數。

③ 多項式的排列
降冪：6x3 ＋ 3x2 ＋ 8x − 4
升冪：−4 ＋ 8x ＋ 3x2 ＋ 6x3

降冪＝次數由大到小；升冪＝由小到大。
為什麼要排？因為排整齊了才好對齊計算——下一節的直式除法就靠這個。

④ 多項式的加減
把同類項合併（係數相加減）

x 的次方相同的項才能合併，而且只動係數。
括號前面是減號時，裡面整串都要變號。

2這些符號從哪來

  
數學曾經是用「寫作文」的


  
你看到的 5x3 − 3x2 ＋ 1 只有九個字元。

  但在符號發明之前，同樣一件事要寫成一整段文字。


  

    
第一階段 · 用文字寫

    
「某數的平方，加上其三倍，等於十」

    
古巴比倫、古埃及、還有九世紀的花拉子米，寫數學題全部用文字敘述——一個符號都沒有。

    
你可以想像那有多難算：要在腦中把整段話翻譯回數量關係，才能開始動筆。算錯多半不是算術錯，是讀錯句子。

  


  

    
第二階段 · 用縮寫

    
丟番圖開始偷懶

    
約公元 250 年，希臘的丟番圖（Diophantus）開始用縮寫符號代替常用字：未知數用一個記號、平方用另一個記號。

    
還不是我們現在的樣子，但已經從「作文」變成「速記」了。

  


  

    
第三階段 · 純符號

    
笛卡兒把它變成現在的樣子

    
韋達（1591）開始用字母代表數；笛卡兒（1637）定下我們今天的寫法——已知數用 a、b、c，未知數用 x、y、z，次方寫在右上角。

    
從那時候起，一個式子可以一眼看完，不必逐句翻譯。

  


  

    
「多項式」這個詞本身就在說它的樣子。

    
英文 polynomial：poly（多）＋ nomial（項）——很多項的東西。

    中文翻成「多項式」，一個字都沒有多。

  


  

    
那「排整齊」又是為了什麼？

    
符號讓式子變短，但還要排對位置才好算——就像整數加法要個位對個位、十位對十位。

    
多項式的降冪排列，就是把同類項排到同一直行。下一節做直式除法時，你會看到這件事有多重要：沒有排好，減法就會對錯欄。

課本 1-2 的四個重點（p.22–29）

  

  

    
內容例

    
x 的多項式由數與 x 用加法和乘法組成的式子
x 在分母或絕對值裡 → 不是多項式		
        4、2x、x2＋3x＋3
2/x ✗　|x| ✗

    
項、係數、次數加號隔開的每一部分＝項
係數不為 0 的最高次項 → 決定次數		
        x3＋7x＋8
三次項 x3（係數 1）
一次項 7x（係數 7）
常數項 8　·　次數 3

    
排列降冪：次數由大到小
升冪：由小到大		
        6x3＋3x2＋8x−4
−4＋8x＋3x2＋6x3

    
加減運算把同類項合併（只加減係數）
        (5x2＋2x＋2)−(3x2−1)
＝2x2＋2x＋3

  

  


  

    
三個最容易錯的地方

    
① 係數忘了帶負號：x2−2x＋5 的一次項係數是 −2，不是 2。減號是係數的一部分。

    
② 沒有 x 項時係數是 0，不是不存在：5x3−3x2＋1 可以看成 5x3−3x2＋0x＋1。下一節做直式除法時，這個 0 要記得留位子。

    
③ 減號後面只變第一項：−(3x2−1) 是 −3x2＋1，兩項都要變。

  


  

    
一句話帶走這一節：多項式的加減沒有什麼技巧，難的是排整齊和變號不出錯。而這兩件事，下一節每一題都要做一次。
